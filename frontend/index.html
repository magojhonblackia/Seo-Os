    ⚙️ Pasos de la auditoría

    Elige qué pasos correr en "Ejecutar auditoría" — útil para probar solo uno sin esperar los demás. Se recuerda para la próxima vez. Los pasos desmarcados simplemente no corren; no borran datos que ya tenías.

    Rango de fechas — Search Console

    Search Console puede mostrar distintos períodos (7 días, 28 días, 3/6/12/16 meses) — elige cuál traer en el paso "Rankings de Search Console". Cada corrida reemplaza los datos de keywords con los del período elegido.

    ⚙️ Configuración

    Guarda tus API keys aquí en vez de editar .env a mano. Un valor guardado aquí reemplaza al de .env mientras esté guardado; "Volver a .env" lo borra y usa el de siempre. La key nunca se muestra de vuelta una vez guardada — solo si está configurada.
